# 🌌 3D Solar System Explorer 🪐

A fully interactive, real-time 3D Solar System simulation built with **Three.js** and vanilla JavaScript. Dive into the cosmos, explore planetary telemetry, and witness the orbital mechanics of our celestial neighborhood right from your browser. 

## ✨ Features

*   **🎨 Zero-Dependency Textures:** Planet surfaces are generated procedurally using HTML5 Canvas. No external image assets required!
*   **🚀 Real-Time Orbital Mechanics:** Watch planets revolve around the Sun with accurate relative speeds, axial tilts, and rotation directions (check out Venus spinning backward!).
*   **🔭 Interactive Telemetry HUD:** Click on any planet or use the side navigation to instantly view real-world data including mean radius, orbit distance, orbital period, and axial rotation.
*   **🖱️ Smooth Camera Tracking:** Features a smart LERP (Linear Interpolation) camera system that smoothly flies to and tracks your selected celestial body.
*   **💫 Stunning Visuals:** Enjoy a dynamic, randomly generated colored starfield, glowing gas giants, Saturn's majestic rings, and Earth's moon.
*   **🎛️ Full Simulation Controls:** 
    *   Pause/Resume the simulation.
    *   Adjust the simulation speed with a sleek slider.
    *   Toggle orbital trajectory lines.
    *   Reset the camera to the Sun.
*   **💎 Glassmorphism UI:** A modern, responsive HUD interface with a sleek frosted-glass aesthetic.

## 🛠️ Tech Stack

*   **Core:** HTML5, CSS3, JavaScript (ES6 Modules)
*   **3D Engine:** [Three.js](https://threejs.org/) (v0.160.0)
*   **Controls:** OrbitControls
*   **Rendering:** WebGL
